EMBERFALL — สองเวอร์ชันมีภาพและแอนิเมชัน
แตก ZIP ทั้งโฟลเดอร์ก่อนเปิด ต้องมี Python 3

1) เกมหน้าต่าง Python + Pygame
เปิด PLAY_DESKTOP.bat
ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อติดตั้ง pygame-ce ใน .venv ของเกม
หลังจากนั้นเล่นออฟไลน์ได้ ภาพทั้งหมดอยู่ใน assets
เลือกอาชีพด้วยเมาส์ แล้วเลือกเส้นทาง/โจมตี/สกิล/ตั้งรับ/ยา
หน้าจอใช้ภาษาอังกฤษเพื่อให้ฟอนต์แสดงผลตรงกัน
ESC กลับเลือกอาชีพใหม่ (เริ่มใหม่ ไม่เก็บความคืบหน้า)
กดปิดหน้าต่างเพื่อออกจากเกม

2) เว็บไซต์ที่ Python คำนวณกติกาจริง
เปิด PLAY_WEBSITE.bat เบราว์เซอร์จะเปิดอัตโนมัติ
หากไม่เปิด คัดลอก URL ที่ขึ้นในหน้าต่างสีดำ เช่น http://127.0.0.1:8765
ต้องเปิดหน้าต่างสีดำค้างไว้ขณะเล่น ปิดด้วย Ctrl+C เมื่อเลิกเล่น
เว็บทำงานบนเครื่องคุณ ไม่ใช่ลิงก์ออนไลน์สำหรับส่งให้คนอื่น
อย่าดับเบิลคลิก web/index.html เพราะต้องมี Python server ทำงาน
เว็บไม่ต้องติดตั้งแพ็กเกจเพิ่ม รีเฟรชแล้วเล่นต่อได้ในแท็บเดิม
หากปิดเซิร์ฟเวอร์ความคืบหน้าจะหาย

ระบบทั้งสองแบบ
3 อาชีพ / 3 ดินแดน / ศัตรู 6 ตัว + บอส 3 ตัว
ภาพ pixel art วาดด้วยโค้ด Python
ตัวละครขยับ โจมตีพุ่ง เอฟเฟกต์สกิล ตัวเลขดาเมจ ฉากชนะ/แพ้
ศัตรูใช้ท่าไม้ตายเทิร์น 3,6,9... ตั้งรับลดดาเมจ 75%
หลังชนะซื้อยา ตีบวก และพักฟื้น

ไฟล์สำคัญ
emberfall_core.py สูตรต่อสู้และฟังก์ชันเดิม
engine.py ควบคุมสถานะและกติกาที่ใช้ร่วมกัน
 desktop_game.py ภาพ การเคลื่อนไหวและคลิกด้วย Pygame
web_server.py รับคำสั่ง เรียก Python engine แล้วส่งผลกลับ
web/index.html หน้าจอเว็บและแอนิเมชัน ไม่คำนวณดาเมจเอง
