04_AI_Evidence
- AI_Conversation_Excerpts.pdf ข้อความคัดเฉพาะช่วงจากแชตจริง
- ควรเพิ่ม Share Link หรือภาพหน้าจอแชตต้นฉบับก่อนส่ง

ก่อนส่งจริงยังต้องทำ
1. ใส่ชื่อจริงและรหัสนิสิตในคู่มือและเอกสารแล้ว ให้ตรวจสะกดก่อนส่ง
2. ทดลองเล่นทั้งโปรแกรมหรือเลือกแบบเดียวเป็นผลงานหลักบนเครื่องจริง
3. ตรวจวิดีโอ และแนะนำอัดเสียงของตนเองเพิ่มตามบทพูด
4. แนบหลักฐาน AI ต้นฉบับเพื่อให้ตรวจย้อนกลับได้
5. ใส่ทั้ง 4 โฟลเดอร์ใน Google Drive ตั้งชื่อ 69540047_ศิริโรจน์_FinalProject
6. เปิดสิทธิ์ให้อาจารย์เข้าถึงและดาวน์โหลด ส่งลิงก์ตามช่องทางที่กำหนด
7. ห้ามลบไฟล์จนกว่าจะได้รับเกรด

ข้อจำกัด
เว็บไซต์นี้เป็น localhost ไม่ใช่เว็บออนไลน์สาธารณะ
การส่งไฟล์โปรแกรมอยู่ในรูปแบบที่โจทย์อนุญาต
ทดสอบกติกาและ API จริง พร้อม render Pygame ในโหมดไม่มีจอ
ยังไม่ใช่การยืนยันว่าเปิดบน Windows ของผู้ใช้สำเร็จ

อัปเดต Notebook: มี Code cells 9 เซลล์และ outputs ที่รันจริง
เปิด EMBERFALL_Development_Manual.ipynb แล้ว Run all จากนั้นไปหัวข้อ 7 เพื่อคลิกเล่น
เกมภาพใน Notebook ใช้ ipywidgets และ HTML/CSS กติกาประมวลผลด้วย Python
ทดสอบทุกเซลล์ใน Jupyter in-process kernel และทดสอบ callback ปุ่ม ไม่ได้คลิกใน Colab จริง
